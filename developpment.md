# tooling

only npm and pnpm seem necessary


# compilation 

For downloading dependencies :  
```sh
$ pnpm install
```

For generating dist files : 
```sh
$ pnpm build
```

Files are availables at : 
```sh
$ ls packages/pinia/dist/
packages  pinia.cjs  pinia.esm-browser.js  pinia.iife.js  pinia.iife.prod.js  pinia.mjs  pinia.prod.cjs
```
